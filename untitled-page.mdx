---
title: "How to Use JeremyAI Skills"
---

Skills help JeremyAI get more specific.

When you ask for a certain kind of business help, JeremyAI can use an available skill to follow a more focused workflow. Skills can help with offers, funnels, ads, messaging, sales calls, follow-up, content, strategy, and other repeat business problems.

You do not need to memorize skill names before using JeremyAI. Start by asking for the outcome you want, with the real business context JeremyAI needs.

## **Ask naturally first**

Most of the time, you can ask JeremyAI naturally. Tell it what you are trying to improve and include the offer, audience, goal, source material, and what is not working.

Example:

`I want JeremyAI to help me improve the VSL for this offer.`\
\
`Offer: [describe the offer]`\
`Audience: [describe the buyer]`\
`Problem: [describe the painful problem they want solved]`\
`Outcome: [describe the result the offer promises]`\
`Current funnel: [describe where the VSL is used]`\
`Source material: [paste a link, notes, transcript, draft, or context]`\
\
`First, tell me what is unclear or missing. Then use the right skill or workflow to build a stronger VSL outline.`\

If your request matches an available skill, JeremyAI can use the right skill for the job.

## **Browse Skills for ideas**

Use the **Skills** area when you want to see what JeremyAI can help with.

The Skills page shows available skills inside JeremyAI. A skill card may include the skill name, what it helps with, and an example request you can try.

Browsing Skills is useful when:

- you are not sure what JeremyAI can do
- you want to see examples of strong requests
- you want to find a specific skill by topic or outcome
- you want ideas for what to ask next

The Skills area is for discovery. It is not a required step before asking JeremyAI for help.

## **Ask for a skill by name**

If you already know which skill you want JeremyAI to use, name it directly in your request.

Example:

`Use the [skill name] skill for this request.`\
\
`Here is the offer, audience, goal, and source material I want you to use:`\
`[add context]`\

This is useful when you found a specific skill in the Skills area and want JeremyAI to use that workflow on your material.

## **Create skills for workers you own**

Skills can also support workers. If you own a worker and skill creation is available, you can create or add skills that help that worker do a repeat job more consistently.

For example, a worker focused on follow-up might use a skill for ghosted-lead follow-up. A worker focused on ads might use a skill for diagnosing ad fatigue or creating direct-response ads.

Use skills with workers when you want a repeat workflow to run in a more focused way each time.

## **Bring the real context**

Skills work best when JeremyAI has the actual material behind the request.

Useful context includes:

- the offer
- the audience
- the funnel or sales path
- the current asset, draft, file, link, script, or notes
- what you already tried
- what is not working
- the output you want

A weak request only names the category of work.

Better request:

`I sell a $2,000 workshop to service business owners. The funnel is supposed to book qualified calls, but people are not making it to the application. I will paste the current VSL outline, offer notes, and landing page context.`\
\
`Review it, tell me the biggest gaps, ask any missing questions, and build a stronger VSL funnel structure.`\

## **If JeremyAI asks questions first**

That is usually a good sign. Some skills need more detail before JeremyAI can create a useful output.

Answer the questions directly. If you do not know an answer, say what you do know and ask JeremyAI to make a reasonable first-pass recommendation.

## **If a skill does not seem to trigger**

Try one of these:

- describe the outcome more clearly
- add the offer, audience, and source context
- ask JeremyAI what information it needs
- use the skill name if you know it
- start a new chat and try the request again

If the issue continues, email [**hey@utari.ai**](mailto:hey@utari.ai) with the prompt, what you expected to happen, what happened instead, and a screenshot if possible.
